# España Corrupta — style guide

- Primary color: Dark crimson (#8B0000). Represents corruption through its similarity to blood, vibrant but professional, contrasts well with a dark background.
- Background color: Very dark gray (#222222). Dark scheme, serious tone.
- Accent color: Dark orange (#D4A373). Highlights points of interaction; distinct from primary and background within the analogous hue range.
- Body and headline font: 'Inter'.
- Single-page leaderboard; the table takes center stage; sticky headers; optimized for desktop and mobile.
- Simple icons for the allegiance categories and for source types.
- Subtle transitions on sort and filter.

Data model and update process: see `src/lib/schema.ts` and `.claude/skills/update-data/SKILL.md`.
